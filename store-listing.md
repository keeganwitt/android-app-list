# App List Store Listings

The values in the `text` blocks are plain text ready to copy into each store's submission form.

## Google Play

[View the published listing](https://play.google.com/store/apps/details?id=com.github.keeganwitt.applist)

### App name

```text
App List
```

### Short description

```text
Compare app details across every app on your device
```

### Full description

```text
App List lets you select one application field and compare it across all the apps on your Android device at a glance.

Available fields:

• App name
• Package name
• APK size
• App size
• Archived status
• Cache size
• Data size
• Enabled status
• Whether the app exists in an app store
• External cache size
• First installed date
• Granted permission count
• Last updated date
• Last used date
• Minimum SDK
• Package manager or installer
• Requested permission count
• Store URL
• Target SDK
• Total size
• Version

Search and sort the app list, show or hide system and archived apps, and view summaries of the selected field. Export any selection of user, system, or archived apps as XML, HTML, CSV, or TSV.

Storage and last-used fields may require optional Usage Access permission.

https://github.com/keeganwitt/android-app-list
```
